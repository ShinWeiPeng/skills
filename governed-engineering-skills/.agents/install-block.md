# Fork installation source

This fork installs Governed Engineering Skills from `marketplace-release` using
the native Windows or Linux launchers described in `README.md`. The governed
plugin version and release workflow are owned by
`plugins/governed-engineering-skills`; upstream root-package release commands
are not this fork's installation or release procedure.

The source Marketplace uses the assembled local artifact for maintainer testing.
Publishing the generated Marketplace tree remains a separate release action.

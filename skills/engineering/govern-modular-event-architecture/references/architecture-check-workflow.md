# Architecture check workflow

Read the same rule version and applicability result used for design. Compare source,
actual callers, types, state and data paths with the approved manifest before
reporting compliance. Run the existing generic checker and applicable analyzers;
regenerate description views and reject stale output. Preserve evidence per AC.
Use the shared [verification map](../../coding-standards/references/verification/rule-verification-map.md).
Unsupported analysis is unverified, not PASS. Release retains zero temporary baseline debt.

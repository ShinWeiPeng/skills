# Shared ADR workflow

Draft at the originating professional Skill. General decisions use the general format; architecture-required decisions use its profile.

Codex MAY draft or revise a proposed ADR. Codex MUST NOT:

- mark its own proposal accepted;
- invent an approver or approval reference;
- widen the exception scope beyond the user's decision;
- use one ADR to suppress unrelated rules or paths.

Only apply an exception when the user explicitly approves it. Keep the exception narrow and link the manifest entry to the ADR.

Preserve decision IDs and supersession links. Never rewrite an accepted decision as if it had always said something else.

## General ADR creation

Create `docs/adr/` only for the first record. Inspect existing numbers and allocate the next number without overwriting a record.

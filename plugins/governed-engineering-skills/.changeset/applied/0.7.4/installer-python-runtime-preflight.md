Validate Python 3.11 or newer before local Plugin assembly. When PATH resolves an
older Python, use the Windows Python Launcher to select a compatible installed
runtime and use that exact interpreter throughout installation.

Recover inherited Windows access only for the exact ignored Plugin artifact,
request UAC only after ordinary recovery fails, and normalize staging ACLs so
future sandbox-created artifacts remain installable by the interactive account.
